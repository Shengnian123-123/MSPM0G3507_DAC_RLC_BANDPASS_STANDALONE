# MSPM0G3507 DAC 输出带通滤波后的矩形波

## 当前实现

本工程不需要外接实际带通电路。MSPM0G3507 直接用 DAC 输出 MATLAB 参考程序中“50 kHz、35% 占空比矩形波经过 RLC band-pass 后，再由 MSPM0 1 MSPS DAC 输出”的阶梯波结果。

- 输入模型：50 kHz、35% 占空比矩形波
- DAC 输出：上述矩形波经过数字带通滤波后的波形
- 带通模型：RLC band-pass
- RLC 参数：R = 1 kOhm，C = 1 nF，L = 1 mH
- RLC 中心频率：约 159.155 kHz
- DAC 更新率：1 MSPS
- 每周期采样点：20
- DAC 输出表：预计算 20 点，DMA_CH1 循环搬运到 DAC0
- DAC 分辨率：12 bit，参考为 VDDA/VSSA

ADC 原有 DMA_CH0 保持不变；DAC 使用 DMA_CH1。

## 接线

不需要接 RLC 或其他外部滤波器。

1. 示波器探头接 PA15/DAC_OUT。
2. 示波器地夹接开发板 GND。
3. 示波器输入建议设为高阻输入。

PA15 输出范围约为 0 V 到 VDDA，不是以 0 V 为中心的双极性信号。当前程序把滤波后的波形偏置在 DAC 中点附近输出。

## 程序位置

主要代码在 `application/dac_waveform.c` 和 `application/dac_waveform.h`。

`DacWaveform_Init()` 中的流程是：

1. 使用 `dac_waveform.c` 中预计算好的 20 点波形表。
2. 配置 DMA_CH1，让 DAC 以 1 MSPS 循环输出这 20 个码值。
3. 每 20 点重复一次，因此输出基波周期为 20 us，即 50 kHz。

当前 DAC 表为：

```text
2658, 3982, 3346, 2349, 1812, 1757, 1900, 1580, 171, 709,
1689, 2256, 2348, 2206, 2063, 2004, 2007, 2026, 2042, 2071
```

## 注意

这里的“带通滤波后的矩形波”指的是：滤波器输入是 50 kHz、35% 占空比矩形波，DAC 输出是这个矩形波经过 MATLAB 中 RLC band-pass 传递函数后的结果。滤波后不再保持理想硬边沿，边沿会被带通算法改变，这是滤波结果本身，不是外接电路造成的。

由于当前 DAC 采样率为 1 MSPS，50 kHz 每周期只有 20 点，输出波形细节受采样点数限制。

本次修改未手动编辑 SysConfig 生成文件。当前已完成源码级修改和 SysConfig 静态检查；实体板示波器验证仍需在硬件上完成。
